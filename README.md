# BittumamaProject

Production website foundation built with Next.js, React, TypeScript, App Router, ESLint, and Tailwind CSS.

## Requirements

- Node.js 20.9 or newer
- npm

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Verification

```bash
npm run lint
npm run build
```

## Phase 1.1

This phase intentionally contains only the technical foundation and a temporary homepage. Product design, branding, data, authentication, payments, and other application features are deferred to later phases.
